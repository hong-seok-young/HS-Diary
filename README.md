# 석영이와 예은이

둘이 같이 쓰는 도트 그래픽 커플 일지.

주소: https://hong-seok-young.github.io/HS-Diary/

## 화면

- **홈**: 우리 그림과 달력만 있어요.
  - 그림 속 이름표에 며칠째인지와 다음 주년까지 남은 날이 보여요.
  - 상대 캐릭터를 누르면 하트가 가요. 내 머리 위 표시를 누르면 오늘 기분을 골라요.
  - 굴러다니는 주사위는 "뭐 하지 뽑기", 물음표 팻말은 "오늘의 질문", 화분은 "우리 텃밭"이에요.
  - 달력의 날짜를 누르면 그날 일정을 보고 바로 적어요. 석영은 파랑, 예은은 분홍, 같이 하는 일정은 노랑. 기념일과 생일도 달력에 표시돼요.
- **기록**: 데이트, 맛집, 카페, 여행, 기념일로 나눈 기록. 장소를 누르면 네이버 지도가 열려요.
- **할 거**: 주말에 할 거 목록. 해내면 체크하고, "기록으로"를 누르면 기록으로 옮겨져요.
- **일기**: 글과 사진. 사진은 좌우로 넘겨 보고, 누르면 크게 보여요.

## 뒤로 가기

- 창, 화면, 게임 어디서든 뒤로 가기를 누르면 바로 전 화면으로 가요.
- 뒤로 단추는 늘 왼쪽 위 같은 자리에 있어요.
- 홈에서는 두 번 눌러야 앱이 꺼져요.

## 홈 풍경

- 위치를 허용하면 그곳의 진짜 날씨를, 아니면 서울 날씨를 보여 줘요. 해의 높이로 하늘 색이 바뀌고 달 모양도 날짜에 맞아요.
- 시간마다 두 사람이 하는 일이 달라요. 기념일에는 소품과 불꽃놀이가 나와요.
- 낙엽, 꽃잎, 눈은 바닥에 쌓이고 비는 웅덩이가 돼요.

## 우리 텃밭 (방치형 게임)

- 밭 9칸에서 작물이 저절로 자라고 코인이 쌓여요. 자리를 비운 동안에도 쌓이고, 돌아오면 한 번에 받아요.
- 코인으로 밭을 키우면 5단계마다 새 작물로 바뀌어요. (무 → 당근 → … → 호박)
- 동물 친구: 하마는 빨리 자라게, 양은 오래 쌓이게, 고양이는 톡톡 누를 때 더 많이.
- 두 사람이 같은 텃밭을 키워요. 둘 다 하루 안에 들르면 "함께 ×1.5".

## 저장 방식

- 처음 열면 "이 폰은 누구 거야?"를 한 번만 물어요. 고르면 바꿀 수 없어요.
- 모든 내용은 먼저 폰에 저장되고, 두 사람 전용 서버(`server/worker.js`, Cloudflare Worker)와 맞춰요.
- 넣을 열쇠나 설정은 없어요. 서버가 폰마다 기기 열쇠를 알아서 줘요.
  - 사람마다 첫 폰은 바로 들어와요.
  - 그다음 새 폰은 쓰던 폰에 "새 폰이 들어오려고 해요" 알림이 뜨고, 허락을 누르면 들어와요.
- 기록과 사진은 허락받은 폰만 읽고 쓸 수 있어요.
- 두 폰은 서버와 줄 하나로 이어져 있어서, 한쪽이 적으면 다른 쪽에 바로 떠요.
- 두 폰이 동시에 고쳐도 항목마다 더 나중에 고친 쪽이 남아요.

## 우리 이야기와 잠옷

- 기록, 할 일 정하기, 할 일 해내기, 일기를 남기면 그 내용에 맞는 짧은 이야기가 떠요.
- 상대가 남긴 이야기는 다음에 앱을 열 때 알림으로 와요.
- 행동에 맞춰 커플 동물 잠옷(16가지)을 하나씩 받아요. 홈 그림 왼쪽 아래 옷장에서 갈아입어요.

## 고칠 수 있는 파일

- `data/config.js`: 이름, 처음 만난 날, 사귄 날, 생일
- `data/questions.js`: 오늘의 질문 목록

## 배포

`main` 브랜치에 올리면 자동으로 사이트에 반영돼요. 일지 내용은 서버에 따로 있어서 코드 배포와 섞이지 않아요. 서버 코드는 `server/worker.js` 예요.
