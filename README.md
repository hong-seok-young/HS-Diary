# 석영이와 예은이

둘이 같이 쓰는 도트 그래픽 커플 일지.

주소: https://hong-seok-young.github.io/HS-Diary/

## 화면

- **홈**: 우리 그림과 달력만 있어요.
  - 그림 속 이름표에 며칠째인지와 다음 주년까지 남은 날이 보여요.
  - 상대 캐릭터를 누르면 하트가 가요. 내 머리 위 표시를 누르면 오늘 기분을 골라요.
  - 날아다니는 종이비행기를 누르면 상대에게 쪽지를 보내요. 비행기는 상대 머리에 콕 꽂히고(맞은 사람은 머리를 부여잡고 엉엉 울어요), 쪽지는 상대의 우체통에 들어가요. 우체통은 깃발과 숫자로 알려 줘요.
  - 오늘의 질문도 우체통으로 와요. 상대가 답하면 알려 주지만, 나도 답해야 상대의 답이 보여요.
  - 집은 옷장, 빨간 지붕 작은 집은 그림에 둘 동물 고르기예요.
  - 이름표는 끌어서 옮기고, 누르면 글자와 모양을 바꿔요. 이름표 아래에는 오늘 일정이나 가장 가까운 일정까지 남은 날이 떠요.
  - 기온은 낮에는 해를, 밤에는 달을 따라다녀요.
  - 달력의 날짜를 누르면 그날 일정이 자세히 보이고, 바로 적거나 눌러서 고쳐요. 일정마다 기간(며칠부터 며칠까지), 종일 또는 시작·끝 시간, 반복(매주, 매달, 매년), 메모를 적어요. 석영은 파랑, 예은은 분홍, 같이 하는 일정은 노랑이고 여러 날 일정은 긴 줄로 보여요. 기념일과 생일도 표시돼요.
- **기록**: 데이트, 맛집, 카페, 여행, 기념일로 나눈 기록. 장소를 누르면 네이버 지도가 열려요.
- **할 거**: 주말에 할 거 목록. 해내면 체크하고, "기록으로"를 누르면 기록으로 옮겨져요.
- **일기**: 글과 사진. 사진은 좌우로 넘겨 보고, 누르면 크게 보여요.

## 뒤로 가기와 새로고침

- 창, 화면, 게임 어디서든 뒤로 가기를 누르면 바로 전 화면으로 가요.
- 뒤로 단추는 늘 왼쪽 위 같은 자리에 있어요.
- 홈에서는 두 번 눌러야 앱이 꺼져요.
- 화면을 아래로 당기면 새로고침돼요. 새 버전이 올라오면 저절로 바뀌어요.
- 새로고침해도 보고 있던 화면과 창, 쓰던 글이 그대로 돌아와요.

## 홈 풍경

- 위치를 허용하면 그곳의 진짜 날씨를, 아니면 서울 날씨를 보여 줘요. 해의 높이로 하늘 색이 바뀌고 달 모양도 날짜에 맞아요.
- 시간마다 두 사람이 하는 일이 달라요. 기념일에는 소품과 불꽃놀이가 나와요.
- 낙엽, 꽃잎, 눈은 바닥에 쌓이고 비는 웅덩이가 돼요.

## 저장 방식

- 처음 열면 "이 폰은 누구 거야?"를 한 번만 물어요. 고르면 바꿀 수 없어요.
- 모든 내용은 먼저 폰에 저장되고, 두 사람 전용 서버(`server/worker.js`, Cloudflare Worker)와 맞춰요.
- 넣을 열쇠나 설정은 없어요. 서버가 폰마다 기기 열쇠를 알아서 줘요.
  - 사람마다 첫 폰은 바로 들어와요.
  - 그다음 새 폰은 쓰던 폰에 "새 폰이 들어오려고 해요" 알림이 뜨고, 허락을 누르면 들어와요.
- 기록과 사진은 허락받은 폰만 읽고 쓸 수 있어요.
- 두 폰은 서버와 줄 하나로 이어져 있어서, 한쪽이 적으면 다른 쪽에 바로 떠요.
- 두 폰이 동시에 고쳐도 항목마다 더 나중에 고친 쪽이 남아요.

## 우리 이야기

- 기록, 할 일 정하기, 할 일 해내기, 일기, 일정을 남기면 그 내용에 맞는 짧은 이야기가 떠요.
- 상대가 남긴 이야기는 다음에 앱을 열 때 알림으로 와요.

## 모으기 (동물, 잠옷, 이름표)

- 동물 도감 557종(`js/zoo.js`) 하나로 **그림 속 동물 557마리**와 **커플 동물 잠옷 557벌**을 그려요. **이름표**는 모양 12가지 × 색 42가지 = 504개예요.
- 하루에 많아야 네 개가 열려요.
  - 석영이 출석하면 동물 한 마리, 예은이 출석하면 잠옷 한 벌
  - 오늘의 질문에 답하거나 하트를 보내면 이름표 하나
  - 그날 처음 기록, 할 일, 일기, 일정을 남기면 셋 중 하나 (날마다 번갈아)
- 열릴 때는 검은 그림자와 짧은 대화가 먼저 나오고, 누르면 폭죽과 함께 모습이 드러나요.
- 한 사람이 열면 둘 다 가져요. 상대가 연 것은 앱을 열 때 맨 먼저 하나씩 보여 줘요.
- 그림 왼쪽 아래 단추나 이름표를 누르면 꾸미기 창이 열려요. 입을 잠옷, 그림에 둘 동물(한 사람 3마리까지), 이름표의 글자와 모양을 골라요. 고른 것은 상대 폰에도 바로 보여요.

## 고칠 수 있는 파일

- `data/config.js`: 이름, 처음 만난 날, 사귄 날, 생일
- `data/questions.js`: 오늘의 질문 목록

## 배포

`main` 브랜치에 올리면 자동으로 사이트에 반영돼요. 일지 내용은 서버에 따로 있어서 코드 배포와 섞이지 않아요. 서버 코드는 `server/worker.js` 예요.
