# 석영이와 예은이

둘이 같이 쓰는 도트 그래픽 커플 일지.

주소: https://hong-seok-young.github.io/HS-Diary/

## 화면

- **홈**: 우리 그림과 달력만 있어요.
  - 그림 속에 이름, 며칠째, 다음 주년까지 남은 날, 다가오는 일정이 표 네 개로 따로 떠 있어요.
  - 상대 캐릭터를 누르면 하트가 가요. 내 머리 위 표시를 누르면 오늘 기분을 골라요. 기분 얼굴은 500가지(마음 20가지 × 얼굴 모양 25가지)이고, 처음엔 하나도 없고 하나씩 열려요. 고른 기분에 맞는 표정을 캐릭터가 가끔 잠깐 지어요.
  - 날아다니는 종이비행기를 누르면 상대에게 쪽지를 보내요. 비행기는 상대 머리에 콕 꽂히고(맞은 사람은 머리를 부여잡고 엉엉 울어요), 쪽지는 상대의 우체통에 들어가요. 우체통은 깃발과 숫자로 알려 줘요.
  - 오늘의 질문도 우체통으로 와요. 상대가 답하면 알려 주지만, 나도 답해야 상대의 답이 보여요.
  - 집은 옷장, 빨간 지붕 작은 집은 그림에 둘 동물 고르기예요.
  - 표 네 개(이름, 며칠째, 기념일, 일정)는 저마다 끌어서 따로 옮기고, 누르면 그 표의 모양을 따로 골라요. 아직 옮기지 않은 표는 이름표 바로 아래에 가지런히 붙어 다녀요. 옮긴 자리와 고른 모양은 두 폰에 똑같이 보여요.
  - 기온은 낮에는 해를, 밤에는 달을 따라다녀요.
  - 달력의 날짜를 누르면 그날 일정이 자세히 보이고, 바로 적거나 눌러서 고쳐요. 일정마다 기간(며칠부터 며칠까지), 종일 또는 시작·끝 시간, 반복(매주, 매달, 매년), 메모를 적어요. 석영은 파랑, 예은은 분홍, 같이 하는 일정은 노랑이고 여러 날 일정은 긴 줄로 보여요. 기념일과 생일도 표시돼요.
- **기록**: 데이트, 맛집, 카페, 여행, 기념일로 나눈 기록. 장소를 누르면 네이버 지도가 열려요.
- **할 거**: 주말에 할 거 목록. 해내면 체크하고, "기록으로"를 누르면 기록으로 옮겨져요.
- **일기**: 글과 사진. 사진은 좌우로 넘겨 보고, 누르면 크게 보여요.

## 뒤로 가기와 새로고침

- 창, 화면, 게임 어디서든 뒤로 가기를 누르면 바로 전 화면으로 가요.
- 뒤로 단추는 늘 왼쪽 위 같은 자리에 있어요.
- 홈에서는 두 번 눌러야 앱이 꺼져요.
- 화면을 아래로 당기면 새로고침돼요. 새 버전이 올라오면 저절로 바뀌어요.
- 새로고침해도 보고 있던 화면과 창, 쓰던 글이 그대로 돌아와요.

## 홈 풍경

- 위치를 허용하면 그곳의 진짜 날씨를, 아니면 서울 날씨를 보여 줘요. 해의 높이로 하늘 색이 바뀌고 달 모양도 날짜에 맞아요.
- 시간마다 두 사람이 하는 일이 달라요. 기념일에는 소품과 불꽃놀이가 나와요.
- 낙엽, 꽃잎, 눈은 바닥에 쌓이고 비는 웅덩이가 돼요.

## 저장 방식

- 처음 열면 "이 폰은 누구 거야?"를 한 번만 물어요. 고르면 바꿀 수 없어요.
- 모든 내용은 먼저 폰에 저장되고, 두 사람 전용 서버(`server/worker.js`, Cloudflare Worker)와 맞춰요.
- 넣을 열쇠나 설정은 없어요. 서버가 폰마다 기기 열쇠를 알아서 줘요.
  - 사람마다 첫 폰은 바로 들어와요.
  - 그다음 새 폰은 쓰던 폰에 "새 폰이 들어오려고 해요" 알림이 뜨고, 허락을 누르면 들어와요.
- 기록과 사진은 허락받은 폰만 읽고 쓸 수 있어요.
- 두 폰은 서버와 줄 하나로 이어져 있어서, 한쪽이 적으면 다른 쪽에 바로 떠요.
- 두 폰이 동시에 고쳐도 항목마다 더 나중에 고친 쪽이 남아요.

## 우리 이야기

- 기록, 할 일 정하기, 할 일 해내기, 일기, 일정을 남기면 그 내용에 맞는 짧은 이야기가 떠요.
- 상대가 남긴 이야기는 다음에 앱을 열 때 알림으로 와요.

## 달력의 공휴일

- 공휴일은 날짜가 빨갛게 보이고 이름이 작게 떠요. 그날을 누르면 "공휴일"로도 나와요 (`js/holidays.js`).
- 들어 있는 것: 신정, 설날 연휴, 삼일절, 노동절, 어린이날, 부처님오신날, 현충일, 제헌절, 광복절, 추석 연휴, 개천절, 한글날, 성탄절, 그리고 대체공휴일.
  - 노동절과 제헌절은 2026년부터 공휴일이에요.
  - 설날, 추석, 부처님오신날은 음력이라 2024~2050년 날짜를 표로 넣어 뒀어요.
  - 대체공휴일은 규칙으로 계산해요. 2027년은 나라에서 발표한 24일과 똑같이 나오는 걸 확인했어요.
- 선거일은 날짜가 정해진 것만 있어요 (2028년 4월 12일 국회의원 선거). 그때그때 정해지는 임시공휴일은 미리 알 수 없어서 없어요.

## 가로로 눕히면 그림만 화면 가득

- 홈에서 폰을 가로로 눕히면 달력과 아래 메뉴가 사라지고 그림이 화면 끝까지 채워져요. 세우면 원래대로 돌아와요.
- 폰의 자동 회전이 꺼져 있어도 돼요 (`js/tilt.js`): 폰의 기울기를 보고, 홈 화면에서 가로로 눕힌 채 0.5초쯤 있으면 화면을 가로로 돌려요. 세우면 풀어요.
  - 안드로이드에서 홈 화면에 깐 앱일 때만 돼요. 아이폰은 앱이 화면을 돌릴 수 없어서, 제어 센터의 세로 고정을 풀어야 돌아가요.
  - 글을 쓰는 중이거나 창이 떠 있을 때, 홈이 아닌 화면에서는 건드리지 않아요.

## 장난 (사람과 동물이 치고받고 던지고)

- 엔진은 `js/play.js`, 장난 순서는 `js/plays.js`(사람끼리, 혼자)와 `js/plays2.js`(사람과 동물, 동물끼리)에 있어요.
- **손으로 하는 것**
  - 사람을 끌어서 던질 수 있어요. 날아가다 벽과 바닥에 튕기고, 다른 사람이나 동물에 맞으면 같이 날아가요. 연못에 떨어지면 풍덩 빠졌다가 헤엄쳐 나와요.
  - 머리 쪽을 잡아 올리면 가끔 머리만 쏙 빠져요. 몸은 허둥지둥 뛰어다니다가, 던져진 머리를 더듬더듬 찾아 다시 얹어요.
  - 세게 던져 벽에 부딪히면 머리·몸통·팔·다리 여섯 조각으로 흩어져요. 다리는 종종걸음으로, 몸통과 팔은 꿈틀꿈틀, 머리는 데굴데굴 굴러와서 스스로 다시 한 사람이 돼요.
  - 잡고 흔드는 동안에도, 던진 뒤에도 상대 폰에서 같이 보여요 (둘 다 앱을 열고 있을 때). 손가락 자리를 서버의 줄(`/live`)로 바로 전해요. 기록에는 남기지 않아요.
- **두 폰에서 같이 보기**: 저절로 시작하는 장난도 한 폰이 시작하면 상대 폰이 같은 장난을 같은 씨앗으로 따라 해요. 누가 이기는지, 어떻게 되갚는지 같은 갈래가 똑같아요. 먼지나 떨림 같은 자잘한 효과, 동물이 서 있던 자리는 폰마다 조금 달라요.
- **저절로 일어나는 것**: 기본 장난 55가지예요. 한 장난이 끝나면 8~16초 쉬었다가 다음 것이 시작돼요.
  - 사람끼리 13가지: 꿀밤, 주먹 한 방, 발차기, 박치기, 눈 찌르기(눈알이 튀어나와 굴러가요), 뿅망치, 들어서 던지기, 머리 뽑기, 뒤에서 놀래키기, 연못에 빠뜨리기, 가위바위보 딱밤, 업어치기, 똥침, 볼 꼬집기, 눈싸움(눈 오는 날).
  - 사이좋은 것 4가지, 혼자 하는 동작 9가지 (옆돌기, 물구나무, 공중제비, 문워크, 재채기 …).
  - 사람과 동물 16가지: 새총 쏘기, 하마 던지기, 동물 뻥 차기, 꼬리 밟기, 저글링, 올라타기, 털 뽑기, 엉덩이 물기, 새가 눈알 물어 가기, 새똥, 냥펀치, 하마 물대포, 들이받기 …
  - 동물끼리 11가지: 박치기, 짓밟기, 뻥 차기, 싸움 구름, 새 낚아채기, 엉덩이 쪼기, 물대포, 꼬리 잡아당기기, 동물 탑 …
- 맞은 쪽은 울거나, 화내며 다른 장난으로 되갚거나, 쫓아가 뒤엉켜 싸우거나, 시치미 떼다 쓰러져요. 그래서 누가 하느냐와 되갚기까지 섞으면 전개가 500갈래쯤 돼요 (그림을 500장 따로 그린 게 아니라 55가지 동작의 조합이에요).
- 피는 안 나요. 혹, 별, 튀어나온 눈알, 납작해진 몸 같은 만화식이고 끝나면 다 원래대로 돌아와요.
- 산책·잠·체조 중이거나 선물·이야기 창이 떠 있으면 장난은 쉬어요.

## 모으기 (동물, 잠옷, 이름표)

- 동물 도감 557종(`js/zoo.js`) 하나로 **그림 속 동물 557마리**와 **커플 동물 잠옷 557벌**을 그려요. **이름표**는 네 조각(이름, 며칠째, 기념일, 일정)이고, 조각마다 자기만의 모양 12가지 × 색 42가지 = 504개씩, 모두 2016개예요. 이름표 선물은 며칠째 → 기념일 → 일정 → 이름 차례로 하나씩 와요.
- **장식품**은 모두 1140개예요: 손에 드는 것 580(간식과 소품 29가지 × 색 20가지), 눈 장식 160(안경, 선글라스, 안대 등), 머리 장식 280(리본, 왕관, 모자, 머리띠 등), 목 장식 120(목도리, 나비넥타이, 목걸이 등). 옷장에서 손, 눈, 머리, 목에 하나씩 골라요.
- **기분 얼굴**은 500개예요(`js/moods.js`): 마음 20가지 × 얼굴 모양 25가지(기본, 곰, 고양이, 토끼, 유령, 떡 등). 처음엔 하나도 없어요.
- 선물은 **한 번 할 때마다 하나**예요. 하루 한도가 없어서 많이 쓰면 많이 받아요.
  - 사람마다 하루 한 번씩: 출석, 오늘의 기분 고르기, 오늘의 질문 답, 하트 보내기
  - 할 때마다: 쪽지, 기록, 할 일 적기, 할 일 해내기, 일기, 일기 댓글, 일정 (일기 반응은 일기마다 한 번)
  - 무엇을 받는지는 차례로 돌아가요 (장식품, 동물, 기분 얼굴, 장식품, 잠옷, 이름표).
  - 기록을 지워도 그 기록으로 받은 선물은 남아요.
- 열릴 때 누가 무엇을 해서 받았는지 알려 줘요 ("예은이가 쪽지를 보내서").
- 열릴 때는 검은 그림자와 짧은 대화가 먼저 나오고, 누르면 불꽃놀이, 파티 폭죽(색종이와 리본), 색종이 비와 함께 모습이 드러나요 (`js/fx.js`).
- 한 사람이 열면 둘 다 가져요. 상대가 연 것은 앱을 열 때 맨 먼저 하나씩 보여 줘요.
- 그림 왼쪽 아래 단추나 이름표를 누르면 꾸미기 창이 열려요. 입을 잠옷, 그림에 둘 동물(둘이 같이 4마리까지), 이름표의 글자와 모양을 골라요. 고른 것은 상대 폰에도 바로 보여요.

## 우리 동네

- 그림 속 동네는 황무지에서 시작해요 (`js/home.js`). 선물을 받은 수(= 한 일의 수)가 차면 한 단계씩, 한 번에 딱 하나씩 바뀌어요. 모두 121단계.
- 집만 바뀌지 않아요. 땅에 풀이 돋고, 새싹이 어린 나무와 큰 나무가 되고(새집, 그네, 나무 위 오두막), 울타리(말뚝, 나무, 흰 칠, 꽃 넝쿨), 횃불과 가로등, 꽃, 디딤돌 길, 연못의 연잎·연꽃·오리 인형, 하늘의 열기구와 무지개가 사이사이에 생겨요.
- 집은 빈터 → 텐트 → 움집 → 초가집 → 통나무집 → 버섯집 → 기와집 → 벽돌집 → 이층집 → 과자집 → 시계탑 집 → 저택 → 작은 성 → 큰 성 → 구름 성. 집마다 살림 들이기, 지붕 새로 칠하기(두 번), 마당 가꾸기, 꾸미기, 공사 중을 거쳐 다음 집이 돼요.
- 무엇이 생겼는지는 그 자리가 통통 튀고 말풍선("새로 생겼어요 · 나무 새싹이 올라왔어요")으로 알려 줘요. 상대가 한 일로 생긴 것도 앱을 열 때 알려 줘요. 집 종류가 바뀔 때는 선물처럼 큰 축하가 나와요.
- 집을 누르면 "우리 동네" 목록(지금까지 생긴 것, 앞으로 생길 것)이 열려요. 옷장은 집 옆 빨랫줄이에요.

## 동물이 자라요

- 새로 온 동물은 알이나 아기로 와서, 그 뒤로 받은 선물 수만큼 자라요 (6, 18, 40번).
- 병아리는 알 → 병아리 → 닭, 개구리는 알 → 올챙이 → 개구리, 나비는 알 → 애벌레 → 번데기 → 나비. 새와 공룡은 알에서, 나머지는 아기에서 시작해요.
- 날아다니는 동물은 종류마다 버릇이 달라요: 새는 미끄러지듯 날다 지붕이나 우체통에 내려앉고, 나비와 벌은 낮게 팔랑거리고, 박쥐는 밤에 날아요.

## 알림

- 상대가 무언가 남기거나 바꾸면 알려 줘요 (`js/notify.js`): 쪽지, 기록·일기·일정·할 일(남김, 고침, 지움), 할 일 해냄, 댓글과 반응, 오늘의 질문 답, 오늘의 기분, 하트. 선물, 옷 갈아입기, 동물 던지기는 알리지 않아요.
- 앱이 켜져 있으면 화면 아래 알림 글로, 꺼져 있으면 폰 알림(Web Push)으로 와요. 폰 알림은 내 폰이 저장할 때 "상대에게 알릴 말"을 같이 올리면 서버(`server/worker.js`)가 상대 폰에 보내요. 내용은 받는 폰만 풀 수 있게 잠가서 보내요.
- 폰 알림을 받으려면 알림을 허용해야 해요. 아이폰은 홈 화면에 설치한 앱에서만 돼요. 서버에는 보내는 쪽 열쇠(`VAPID_JWK`)가 비밀값으로 들어 있어야 해요.

## 허락한 기기 목록 (석영 폰에서만)

- 우체통을 열면 맨 오른쪽에 톱니바퀴 단추가 있어요. 석영이로 들어온 폰에서만 보여요.
- 우리 기록을 볼 수 있는 폰이 모두 몇 대인지, 저마다 누구 폰이고 어떤 폰인지, 언제 들어왔고 누가 허락했는지, 마지막으로 연 때가 언제인지 보여 줘요.
- 서버(`/mydevices`)도 석영 폰의 열쇠가 아니면 목록을 주지 않아요. 열쇠 자체는 어디에도 내보내지 않아요.
- 누가 허락했는지는 이 기능이 생긴 뒤에 들어온 폰부터 적혀요. 어떤 폰인지는 그 폰에서 앱을 한 번 열면 채워져요.

## 폰 상태 기록

- 화면에는 없어요. 폰마다 누구 폰으로 골랐는지, 무슨 폰·브라우저인지, 홈 화면에 설치해서 쓰는지, 알림을 허용했는지, 처음 연 때와 마지막으로 연 때를 서버에만 적어 둬요 (`js/phones.js`, 서버 기록의 `st:<기기 번호>`).

## 처음부터 다시 시작

- `data/config.js` 의 `resetAt` 을 지금 시각으로 바꿔 올리고 서버를 비우면, 두 폰에 남은 기록과 누구 폰인지까지 모두 지워져요.

## 고칠 수 있는 파일

- `data/config.js`: 이름, 처음 만난 날, 사귄 날, 생일
- `data/questions.js`: 오늘의 질문 목록

## 배포

`main` 브랜치에 올리면 자동으로 사이트에 반영돼요. 일지 내용은 서버에 따로 있어서 코드 배포와 섞이지 않아요. 서버 코드는 `server/worker.js` 예요.
