# 석영이와 예은이

둘이 같이 쓰는 도트 그래픽 커플 일지.

주소: https://hong-seok-young.github.io/HS-Diary/

## 화면

- **홈**: 풍경, D+ 숫자, 오늘의 기분, 하트 보내기, 오늘의 질문, 뭐 하지 뽑기, 기념일, 통계
- **기록**: 데이트, 맛집, 카페, 여행, 기념일로 나눈 기록. 장소를 누르면 네이버 지도가 열려요.
- **할 거**: 주말에 할 거 목록. 해내면 체크하고, "기록으로"를 누르면 기록으로 옮겨져요.
- **일기**: 글과 사진. 사진은 좌우로 넘겨 보고, 누르면 크게 보여요.

기록과 할 거에는 석영, 예은 하트를 각자 따로 눌러서 줄 수 있어요.

## 홈 풍경

- 위치를 허용하면 그곳의 진짜 날씨(맑음, 구름, 비, 천둥, 눈, 안개, 바람, 기온)를 보여 줘요. 허용하지 않으면 서울 날씨예요.
- 해의 높이로 새벽, 해 뜰 녘, 아침, 오후, 노을, 해 질 녘, 저녁, 밤, 늦은 밤 하늘을 그려요. 달 모양도 날짜에 맞게 바뀌어요.
- 시간마다 할 일: 아침 7~9시 커피, 12~1시 점심 도시락, 3~4시 간식, 6~7시 저녁 식사, 8~11시 모닥불, 밤 11시 잘 시간, 새벽 꿈나라, 주말 낮 연날리기.
- 생일, 100일 단위, 주년, 매달 사귄 날, 처음 만난 날, 크리스마스, 새해, 밸런타인데이, 화이트데이, 빼빼로데이, 핼러윈에는 소품과 불꽃놀이가 나와요.
- 낙엽, 꽃잎, 눈은 바닥에 쌓이고 비는 웅덩이가 돼요.

## 눌러 볼 것

- 바닥: 쌓인 낙엽이 날리고, 눈을 퍼내고, 웅덩이에서 첨벙.
- 쓸어 넘기기: 바람이 불어요.
- 하늘: 낮에는 새, 밤에는 별똥별, 기념일 밤에는 불꽃놀이.
- 해를 빠르게 다섯 번: 무지개.
- 캐릭터, 나무, 꽃, 구름, 고양이, 연, 풍선, 눈사람, 모닥불도 눌러 봐요.
- 날씨 표시: 지금 날씨를 알려 주고 새로 받아 와요.
- D+ 숫자: 누를 때마다 주, 개월, 시간으로 바뀌어요.

## 같이 키우기

화분을 누르거나 "나무" 타일을 누르면 열려요.

- 물 주기(하루 3번), 쓰다듬기, 비료(코인 10), 벌레 잡기, 잡초 뽑기로 키워요.
- 씨앗, 새싹, 떡잎, 꽃봉오리, 꽃, 열매 순서로 자라고 다 크면 수확해서 도감에 담아요.
- 같은 날 둘 다 돌보면 보너스, 며칠 연속인지 세어요. 진짜 비가 오면 저절로 물을 줘요.
- 하트 코인은 기록, 일기, 할 거, 질문 답, 하트 보내기, 게임으로 모이고 비료와 화분에 써요.
- 수확할수록 새 씨앗이 열려요. 해바라기, 튤립, 딸기, 토마토, 장미, 선인장, 네잎클로버, 벚꽃나무, 사과나무, 그리고 숨은 꽃 하나.
- 도전 과제를 끝내면 코인을 받고, 커플 레벨이 올라가요.

## 저장 방식

- 적은 내용은 먼저 그 폰에 저장돼요.
- 설정에서 깃 토큰을 연결하면 이 저장소의 `data` 브랜치(`db.json`, `photos/`)에 올라가고, 두 폰에서 같이 보여요.
- 두 폰이 동시에 고쳐도 항목마다 더 나중에 고친 쪽이 남아요. 하트, 기분, 답변은 사람별로 따로 합쳐져요.

### 토큰 만들기 (한 번만)

1. 깃허브 Settings, Developer settings, Fine-grained tokens 에서 Generate new token.
2. Repository access 는 Only select repositories 로 `HS-Diary` 하나만.
3. Permissions 의 Contents 를 Read and write 로.
4. 만들어진 토큰을 사이트 설정(홈 화면 톱니바퀴)의 "깃 저장 연결" 칸에 붙여 넣어요. 두 폰 모두 같은 토큰을 넣어요.

토큰은 각 폰 안에만 저장되고 저장소에는 올라가지 않아요.

## 고칠 수 있는 파일

- `data/config.js`: 이름, 처음 만난 날, 사귄 날, 생일
- `data/questions.js`: 오늘의 질문 목록

## 배포

`main` 브랜치에 올리면 자동으로 사이트에 반영돼요. 일지 내용은 `data` 브랜치에 따로 있어서 코드 배포와 섞이지 않아요.
